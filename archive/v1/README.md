# 山境 / Mountain

按 EPIX Pro（Gen 2）51mm、454 × 454 屏幕制作的原生佳明数字表盘。以用户提供的「望山-X」和说明视频为方向参考，重新设计山形、配色、数据布局和进度表达。原版代码与美术资源没有被提取或使用。

## 先看效果

双击 `山境-打开预览.html`，无需安装依赖或联网。页面数值为演示数据，可切换 12 种景色和状态。原生表盘与预览共用山景几何和数字字体；浏览器抗锯齿、刷新节奏与实机可能不同。

三景并排图在 `build/three-scenes.png`。`gallery.html` 和 `preview.html` 是供本地开发服务器使用的版本。

## 当前设计

- 远山、雪峰、山麓、松林构成景深；时间位于黑色区域，避免景色影响读时。
- 外圈暖色细线表示手表当天步数目标完成度。
- 上方显示日期和电量；两侧显示海拔、天气温度；下方显示步数、心率、每日总卡路里。
- 自动时段按手表本地时间：06:00–07:00 晨光、07:00–17:00 白天、17:00–19:00 夕照、19:00–06:00 夜间。这不是按 GPS 计算的日出日落。
- 夜间星点、雨线和火星在亮屏时随秒变化。息屏时不播放场景动画，只画暗色小钟并按分钟移动。
- 在系统提供的表盘设置入口中，使用中文菜单选择自动、白天、夜间、日照金山。此菜单已经实现，实机入口与选择体验尚待验证。

## 状态与真实数据

| 状态 | 原生触发条件 |
| --- | --- |
| 雨景 | Garmin 天气缓存中的降水概率 ≥ 60%；代表可能下雨，不是现场雨量 |
| 山口微光 | 最近有效压力值 ≥ 70 |
| 彩虹 | 当日总卡路里 ≥ 2500 kcal，包含基础代谢与活动消耗 |
| 闪电 | 电量 ≤ 20%，或系统报告正在充电 |
| 起身提醒 | Garmin 久坐进度条已启动 |
| 消息数 | 系统未读通知数量大于 0，不访问通知内容 |

压力、低电量、卡路里阈值在 Connect IQ 设置资源中可调整。旁加载版本不保证出现在手机商店的设置列表中；手表端目前提供天空选择。

心率超过 5 分钟、海拔或压力超过 15 分钟、天气超过 2 小时的数据不再显示。无数据时显示 `--`。日期和时间使用系统时间及 12/24 小时偏好。海拔和温度目前固定使用米、摄氏度。

仅申请 SensorHistory 权限。天气读取 Garmin 提供的缓存，无外部天气账号、API 密钥或网络上传逻辑。天气是否可用仍取决于设备与手机同步。

## 安装文件

`build/Mountain.prg` 是 EPIX Pro 51mm 的发布编译文件，独立应用 ID，不与原表盘共用 ID。未复制到真实手表。

旁加载方式：手表通过 USB 连接电脑，在设备存储的 `GARMIN/APPS` 中复制 `Mountain.prg`，安全断开后在手表表盘列表里选择「山境 Mountain」。不同固件的导入行为仍需实机确认。

## 本地开发

依赖本目录旁的 `../watchface-install/sdk`、已有的开发签名密钥、Java 17 和 Python/Pillow。签名密钥未复制进本项目。

```powershell
python generate_assets.py
python build.py
python make_preview.py
python test_native.py
```

生成字体使用本机 Windows Impact 与 Bahnschrift，仅提供本地自用构建。若将来公开发行，应先换成允许再分发的字体并补齐许可证。

测试需要先运行官方 `sdk/bin/simulator.exe`。受限沙箱里可能出现 DLL 错误，在正常 Windows 环境运行官方组件可以启动。`test_native.py` 用原生模拟器测试各主题、息屏、唤醒、降雨、压力和缺失数据的绘制，结果在 `build/native-test.log`。测试代码只参与测试构建；正式 PRG 不启用演示数据。
